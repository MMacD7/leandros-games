# Credits

## Thunder Lion

The body is the "Mountain Lion" model by Momus Park.

- File: `assets/models/lion.glb`
- Source: https://models.codelove.in/models/momuspark-mountain-lion/
- License: CC0 1.0 (public domain). https://creativecommons.org/publicdomain/zero/1.0/
- The file shipped here is that model with the meshopt compression removed so the game can load it. The gold color, the fiery mane, the glowing eyes and the chest bolt are added by this game. There is no armor and no franchise mark.

It is a low-poly big cat (about 2,500 triangles), not a sculpted heroic lion. A more detailed CC-BY lion on Sketchfab (kenchoo, https://sketchfab.com/3d-models/lion-66be3258e2d64f32af2b73b2ecd47637) could not be downloaded from this environment because Sketchfab requires a signed-in download.
